## 二、待开发功能规划

### Phase 1 - 基础体验增强（高优先级）

#### 1. 全局搜索功能
- **功能描述**：在所有页面提供搜索入口，支持搜索歌曲、专辑、艺人
- **技术实现**：
  - 使用 Jellyfin API `/Items` 端点进行搜索
  - 支持实时搜索（输入时即时显示结果）
  - 搜索结果分类展示（歌曲、专辑、艺人）
  - 搜索历史记录

#### 2. 播放列表管理
- **功能描述**：创建、编辑、删除播放列表
- **技术实现**：
  - 使用 Jellyfin API 创建用户播放列表
  - 支持从当前队列保存为播放列表
  - 支持添加/移除播放列表中的歌曲
  - 播放列表封面显示

#### 3. 歌词显示
- **功能描述**：在全屏播放器中显示歌词
- **技术实现**：
  - 从 Jellyfin 获取歌词元数据
  - 支持 LRC 格式歌词解析
  - 歌词随播放进度滚动高亮
  - 手动滑动歌词定位

#### 4. 睡眠定时器
- **功能描述**：设置播放定时停止
- **技术实现**：
  - 提供 15/30/45/60 分钟选项
  - 支持自定义时间
  - 剩余时间显示
  - 定时器取消功能

---

### Phase 2 - 进阶功能（中优先级）

#### 5. 音效均衡器
- **功能描述**：内置音效调节
- **技术实现**：
  - 使用 AVAudioEngine 实现均衡器
  - 预设音效（流行、摇滚、古典、爵士等）
  - 自定义均衡曲线
  - 音效开关控制

#### 6. 播放统计与历史
- **功能描述**：记录播放历史和统计数据
- **技术实现**：
  - 本地存储播放记录
  - 统计最常播放的歌曲/专辑/艺人
  - 播放次数、总播放时长统计
  - 最近播放列表

#### 7. 智能推荐
- **功能描述**：基于播放历史推荐内容
- **技术实现**：
  - 使用 Jellyfin 的推荐 API
  - 基于用户数据生成推荐
  - 推荐专辑/歌曲展示

#### 8. 分享功能
- **功能描述**：分享当前播放内容
- **技术实现**：
  - 支持分享到社交平台
  - 生成分享链接
  - 复制链接功能

---

### Phase 3 - 高级特性（低优先级）

#### 9. CarPlay 支持
- **功能描述**：支持苹果车载系统
- **技术实现**：
  - 实现 CarPlay 界面
  - 支持车载控制
  - 仪表盘显示

#### 10. 家庭共享
- **功能描述**：支持家庭共享媒体库
- **技术实现**：
  - 集成家庭共享 API
  - 共享播放列表
  - 家庭成员管理

#### 11. 播客支持
- **功能描述**：支持 Jellyfin 播客库
- **技术实现**：
  - 播客列表展示
  - 订阅管理
  - 播放进度记忆

#### 12. 桌面小组件
- **功能描述**：iOS 桌面小组件
- **技术实现**：
  - 播放状态小组件
  - 快捷控制小组件
  - 最近播放小组件

## 三、技术优化建议

### 性能优化
1. **图片缓存优化**：增强封面图片缓存策略，支持磁盘缓存
2. **网络请求优化**：实现请求合并、重试机制
3. **内存优化**：优化播放器内存占用，及时释放资源

### 用户体验优化
1. **流畅动画**：增强页面切换、列表滚动的动画效果
2. **错误处理**：统一错误提示风格，提供重试机制
3. **加载状态**：优化加载指示器，提供加载进度反馈

## 七、技术实现要点

### 搜索功能实现
- 使用 `JellyfinClient` 添加搜索方法
- 实现搜索历史本地存储
- 创建 `SearchTabView` 视图（Tab 页方式）

### 播放列表实现
- 使用 Jellyfin API 的 `/Playlists` 端点
- 创建 `PlaylistView` 和 `PlaylistDetailView`
- 实现播放列表管理视图模型

### 歌词显示实现
- 解析 LRC 格式歌词
- 创建 `LyricsView` 组件
- 同步歌词与播放进度

### 睡眠定时器实现
- 使用 `Timer` 实现定时功能
- 创建 `SleepTimerView` 设置界面
- 在 `PlayerManager` 中集成定时器逻辑

### 音效均衡器实现
- 使用 `AVAudioEngine` 和 `AVAudioUnitEQ`
- 创建 `EqualizerView` 组件
- 预设音效配置管理

---

## 八、注意事项

1. **API 兼容性**：确保与 Jellyfin 10.8+ 版本兼容
2. **网络状态**：考虑离线状态下的功能降级
3. **权限管理**：处理必要的系统权限（如网络、存储）
4. **后台播放**：确保后台播放时功能正常
5. **内存管理**：避免内存泄漏，及时释放资源
